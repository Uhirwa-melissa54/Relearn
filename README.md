# 📚 ReLearn MIS (Management Information System)

## 📖 Overview
**ReLearn MIS** is a web-based Management Information System designed to help schools manage students, attendance, and academic work submissions efficiently.

It provides a centralized platform for **admins, teachers, and students** to interact, track progress, and manage educational activities.

---

## 🎯 Objectives
- Simplify student management
- Track attendance effectively
- Manage assignment submissions
- Improve communication between users
- Build a scalable academic system

---

## 👥 User Roles

### 👨‍💼 Admin
- Manage students and teachers
- View reports and system data
- Monitor overall system activities

### 👩‍🏫 Teacher
- Mark student attendance
- Create and manage assignments
- Review and grade submissions

### 🎓 Student
- View assignments
- Submit work
- Track attendance and feedback

---

## ⚙️ Features

### 📌 Student Management
- Register students
- Update student information
- View student records

### 🕒 Attendance Management
- Mark daily attendance
- View attendance history
- Generate reports

### 📝 Assignment & Submission
- Teachers upload assignments
- Students submit work
- Track deadlines
- Grading system

### 📊 Dashboard & Reports
- Attendance summaries
- Submission tracking
- Performance insights

---

## 🏗️ Architecture

The system follows a layered architecture:

- **Controller Layer** → Handles HTTP requests
- **Service Layer** → Business logic
- **Repository Layer** → Database operations
- **Entity Layer** → Data models
